# Word 与完整文件下载

完整 Word 文件约 35.5 MiB，因此整套可编辑文件通过本仓库的 GitHub Releases 提供。

在仓库主页右侧点击 Releases，打开 v1.11 版本，在 Assets 中下载 `book-v1.11-public.zip`。解压后：

- `pdf/book-v1.11.pdf` 是整本书的阅读版。
- `pdf/volume-01-v1.11.pdf` 至 `volume-05-v1.11.pdf` 是五卷 PDF。
- `editable/book-v1.11.docx` 是合订本 Word。
- `editable/volume-01-v1.11.docx` 至 `volume-05-v1.11.docx` 是五卷 Word。
- `manuscript.md`、`manuscript/` 与 `assets/` 是 Markdown 源稿及配套图件。

如果直接从 GitHub 下载仓库的 Source code ZIP，得到的是仓库快照，其中不包含 Word。请使用上面指定的公开下载包取得可编辑版本。

打开 Word 后如果只做阅读，无需更新目录或重新排版。不同系统和字体可能影响 Word 的分页，固定版式阅读请优先使用 PDF。
