# 图像与素材说明

本仓库保留 v1.11 源稿直接引用的 57 个图像文件，另保留一张整书正封预览。图件目录中的 v1.9 和 v1.2 是沿用素材的版本编号，不表示正文版本。

本版封面与主题插画使用生成式图像工具制作。其中十幅 v1.11 主题插画包括五幅卷图和五幅正文插画，经过选图、排版与检查。它们属于编辑性主题插画，不是现场照片、历史复原或工程图纸，不能把它们作为历史或经验事实的证据，也不能宣称为人工绘制。

数据、机制与公式图以正文说明和资料引用为依据。主题插画与这些论证图件的用途不同。

公开阅读包未包含封面展开样张、字体文件、临时依赖和印刷生产材料。印刷所需的书脊、出血与色彩校准，应另行处理。
