# 完整文件下载

在仓库主页右侧点击 Releases，打开 v1.11 版本，在 Assets 中下载 `book-v1.11-public.zip`。解压后：

- `pdf/book-v1.11.pdf` 是整本书的阅读版。
- `pdf/volume-01-v1.11.pdf` 至 `volume-05-v1.11.pdf` 是五卷 PDF。
- `manuscript.md` 是整合 Markdown 源稿。
- `manuscript/` 是五卷 Markdown 源稿。
- `assets/` 是封面预览和源稿配套图件。

公开下载包包含 PDF、Markdown 和图件。PDF 保留封面、目录、图表与分页，适合连续阅读；Markdown 适合在线浏览、检索和离线阅读。离线浏览 Markdown 时，请保留相邻的 assets 目录及其层级。

文件完整性可用包内的 SHA256SUMS.txt 校验；Release 附带的同名校验文件用于核对整个 ZIP。
